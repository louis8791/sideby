# Sideby 關鍵字與持續發展盤點

查核日：2026-09-06。權威：根 AGENTS／PRD／TDD／ROADMAP；現況為已合併及部署的正式版本。

## 34 個選項的實際狀態

完整清單見 [PRD](../PRD.md)。原 30 個為 UI 感受標籤，已全部映射至 21 個計分屬性；新增 4 個為結構化環境硬限制。選項可辨識不等於每個場地都有相應屬性證據，兩者不得混稱。

| 狀態 | 項目 |
|---|---|
| 已有明確計分映射（30） | 浪漫、放鬆、安靜、有趣、有質感、療癒、有儀式感、新鮮感、熱鬧、私密感、輕鬆隨性、特別一點、有點累、精神很好、不想動腦、想聊天、想放空、想走走、想做點事情、想被照顧、好好聊天、一起體驗、一起吃東西、散步、看展 / 看表演、一起拍照、動手做東西、找新店、小酌、看夜景 |
| 環境硬限制（4） | 戶外（含戶外區）、室內、冷氣、無冷氣 |

環境每組單選／不限，適用每站。戶外＋冷氣並非語意上不可能，但必須同一實際戶外區有已確認的冷氣；找不到就失敗。冷氣未知不是無冷氣；半戶外未確認類型就不得擅自分類。室內與戶外可以在同店以不同 execution slot 表示，新行程顯示區域且重排保留已鎖定區域。

程式位置：`frontend/src/routes/index.tsx`（選擇、正規化與送出）、`src/model/preference-query.ts`（語意／schema）、`src/server/private-inputs.ts`（本人保存）、`src/recommendations/engine.ts`（硬限制與區域）、`src/server/itineraries.ts`（鎖定後重排）。

## 已有什麼可以繼續長大

| 既有功能／基礎 | 對反覆使用或開發的價值 | 已有證據／限制 |
|---|---|---|
| 私人場地清單、想去／去過、筆記、評分、標籤 | 留下本人可回看的約會資料 | `src/server/feedback.ts`；後端 API 已有，不等於主畫面全部管理流程或下次候選自動回用已完成 |
| 版本化同意、個人化設定、本次／記住分離 | 允許長期偏好在可撤回界線內累積 | `src/server/feedback.ts`、`src/server/private-inputs.ts`；七日匿名憑證無穩定跨裝置復原 |
| 五種本人負面回饋與偏好投影 | 可針對太暗、太吵、太幼稚、太正式、走太多調整後續計算並降低該地點排序 | `src/model/preference-learning.ts`、`src/server/itineraries.ts`；是可追溯個人規則，不是泛化模型訓練 |
| 反應、鎖站、局部重排、雙方定案 | 修改不滿意部分，同時保留已有共識 | `src/server/itineraries.ts`；合成資料測試，不是使用者已證明滿意 |
| 自有／授權場地、來源與查核、版本、區域／冷氣 | 1,121 筆政府候選可進正式比較池並持續更新 | `src/venues/`、`db/`；只有 13 筆完整驗證，1,108 筆須明示待確認，Google 展示資訊不能轉成自有資料庫 |
| Gemini 可選接點＋本機規則＋獨立硬限制 | 可換解析方式，仍保留權限與可驗證結果 | `frontend/src/lib/preferences.functions.ts`、`src/model/`；免費層非敏感展示已驗，真實私密資料、評論候選／理由改寫待接 |
| 同一 Repo 分層、migration、schema 與回歸測試 | 三人可持續分工維護，新增功能有共同驗收入口 | `docs/TEAM_INTEGRATION.md`、`npm run check:all`；不是負載、單位成本、留存或營收證據 |

可發展性的核心不是檔案數，而是「本人資料可累積、共識可接續、場地可更新、規則可測試」。目前尚未證明的項目包括：廣泛自動學習、跨城市覆蓋、商家自助更新、預訂／交易、付費模式、產品市場契合。這些只能列未來方向。

## 如何驗證有人願意用

先驗證「兩人決策」是否優於各自慣用方法，而不是只問喜不喜歡 AI。探索性測試提案（尚未執行）：招募 30–50 對大臺北伴侶，在同等時間／預算需求下，以交叉順序比較 Sideby 與慣用工具；記錄開始到雙方定案時間、共同完成率、未滿足限制、主觀負擔、是否真的出門及 30 日再用。人數不是代表性保證，正式檢定樣本量須依先導變異估計。

只在另有研究告知與同意後蒐集最小必要的匿名彙總事件；不將私密文字、精確位置、伴侶身分或憑證送分析服務。定案率分母用啟動且符合資格的雙人 Session，再用率分母用可追蹤且完成首用的伴侶，不用瀏覽量冒稱使用人數。公開研究的整理與限制另見 [需求證據](DEMAND_EVIDENCE.md)。
